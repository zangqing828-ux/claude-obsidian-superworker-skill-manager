# Personal Obsidian Workflow

> **版本**: 5.0.0
> **目的**: 记住用户的 Obsidian 工作流配置和偏好，智能搜索文件，统一管理 Skills
> **更新**: 2026-02-11
> **说明**: 本技能专注于个人工作流配置，技能管理请使用 skill-dashboard-generator

---

## 🎯 技能概述

这个技能帮助 Claude Code 记住用户的个人 Obsidian 配置和工作习惯：

1. **记住 Vault 位置** - 知道在哪里创建文件
2. **自动分类文档** - 根据文档类型放到正确的文件夹
3. **智能文件搜索** - 快速查找 Vault 中的文件
4. **学习用户偏好** - 持续更新记忆和优化工作流
5. **保持一致性** - 确保所有文档遵循相同的结构

> 💡 **注意**: 技能管理和仪表盘功能已拆分到 **skill-dashboard-generator**

## 📁 用户配置

### Vault 路径

> ⚠️ **注意**: 这是示例路径，实际使用时请替换为您的 Vault 路径

\`\`\`bash
# macOS/Linux 示例
主 Vault: ~/Documents/MyKnowledgeBase

# Windows 示例
主 Vault: C:\Users\YourName\Documents\MyKnowledgeBase

# 或者在对话中告诉 Claude Code 您的 Vault 路径
\`\`\`

### 目录结构与分类规则

| 文件夹编号 | 文件夹名称 | 存放的文档类型 | 触发关键词 |
|-----------|-----------|--------------|-----------|

| \`02-技术文档/\` | 技术文档 | API 文档、代码说明、技术笔记 | API, 接口文档, 代码说明, 技术笔记 |
| \`03-架构设计/\` | 架构设计 | ADR、系统架构、数据模型 | ADR, 技术决策, 系统架构, 数据模型, 数据库设计 |
| \`04-会议纪要/\` | 会议纪要 | 会议记录、讨论总结 | 会议, 纪要, 讨论, 同步 |
| \`05-学习笔记/\` | 学习笔记 | 学习记录、教程笔记、读书笔记 | 学习, 教程, 读书笔记, 课程笔记 |
| \`06-项目管理/\` | 项目管理 | 任务追踪、进度报告、里程碑 | 任务, 进度, 里程碑, TODO, 复盘 |
| \`07-快速记录/\` | 快速记录 | 临时笔记、灵感、草稿 | 笔记, 灵感, 草稿, 快速记录, memo |
| \`99-归档/\` | 归档 | 已完成、过期或不再活跃的文档 | 归档, 已完成, 已关闭 |

### 符号链接（外部项目）

> ⚠️ **注意**: 这是示例配置，请根据您的实际项目路径修改

| 链接名称 | 目标路径 | 用途 |
|---------|---------|------|
| \`项目A文档\` | \`/path/to/project-a/docs\` | 项目 A 文档 |
| \`项目B文档\` | \`/path/to/project-b/docs\` | 项目 B 文档 |

**如何创建符号链接**:
\`\`\`bash
# macOS/Linux
ln -s /path/to/project/docs "{VAULT}/项目文档"

# Windows (管理员权限)
mklink /D "C:\path\to\vault\项目文档" "C:\path\to\project\docs"
\`\`\`

## 🔍 智能文件搜索

### 搜索方式

| 搜索类型 | 命令格式 | 说明 | 示例 |
|---------|-----------|------|------|----------|
| **标题搜索** | \`搜索标题 [关键词]\` | 按文件名搜索 | \`搜索标题 PostgreSQL\` |
| **全文搜索** | \`搜索内容 [关键词]\` | 搜索文件内容 | \`搜索内容 数据库选择\` |
| **标签搜索** | \`搜索标签 [标签]\` | 按标签筛选 | \`搜索标签 ADR\` |
| **模糊搜索** | \`模糊搜索 [描述]\` | 智能匹配 | \`模糊搜索 关于数据库的决策\` |
| **最近文件** | \`最近文件 [数量]\` | 列出最近修改的文件 | \`最近文件 10\` |
| **按文件夹** | \`列出 [文件夹]\` | 列出指定文件夹 | \`列出 03-架构设计/\` |

### [文件夹名称]
- [[文件名]] - [简短描述/标签]

## 🎯 工作流规则

### 规则 1: 自动分类文档

当用户要求创建文档时：

1. **分析文档类型** - 根据标题、内容、关键词判断
2. **选择正确文件夹** - 使用上面的分类规则表
3. **创建文件** - 在选定文件夹中创建文件
4. **记录到记忆** - 更新用户使用模式

### 规则 2: 文件命名规范

| 文档类型 | 命名格式 | 示例 |
|---------|---------|------|----------|
| PRD | \`PRD-{项目名称}-{日期}.md\` | \`PRD-移动端笔记应用-2026-02-11.md\` |
| ADR | \`ADR-{YYYY-MM-DD}-{简短描述}.md\` | \`ADR-2026-02-11-数据库选择.md\` |
| 会议纪要 | \`会议-{日期}-{主题}.md\` | \`会议-2026-02-11-产品评审.md\` |

## 🚨 注意事项

### 1. 始终确认

- 对于**重要文档**（PRD、ADR），在创建前确认文件夹位置
- 对于**不确定的分类**，询问用户而不是猜测
- 对于**项目文档**，确认是否使用符号链接

### 2. 保持一致性

- 所有文档使用相同的命名规范
- 所有同类型文档放在同一文件夹
- 保持 wikilink 的一致性

### 3. 主动学习

- 记录用户的修正和调整
- 根据使用模式优化建议
- 定期建议配置更新
