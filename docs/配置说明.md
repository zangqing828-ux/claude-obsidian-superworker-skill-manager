## 依赖安装

### Python 安装

#### macOS

```bash
# 使用 Homebrew（推荐）
brew install python3

# 或使用官方安装包
# 访问 https://www.python.org/downloads/
```

#### Linux (Ubuntu/Debian)

```bash
sudo apt update
sudo apt install python3 python3-pip
```

#### Windows

```powershell
# 使用 Windows Package Manager (winget)
winget install Python.Python.3.11

# 或从官网下载安装包
# https://www.python.org/downloads/windows/
```

### 验证 Python 安装

```bash
# 检查版本
python3 --version

# 检查 pip
pip3 --version
```

## 技能配置

### 1. 安装 obsidian-skills（推荐）

```bash
# 克隆官方技能包
git clone https://github.com/kepano/obsidian-skills.git

# 复制到 Claude Code skills 目录
cp -r obsidian-skills/skills/* ~/.claude/skills/

# 验证安装
ls ~/.claude/skills/
```

### 2. 安装 CC+OB-open 技能

```bash
# 进入项目目录
cd CC+OB-open

# 复制技能到 Claude Code
cp -r skills/personal-obsidian-workflow ~/.claude/skills/
cp -r skills/skill-dashboard-generator ~/.claude/skills/

# 验证安装
ls ~/.claude/skills/ | grep -E "(personal-obsidian-workflow|skill-dashboard-generator)"
```

### 3. 配置 personal-obsidian-workflow

编辑 `~/.claude/skills/personal-obsidian-workflow/SKILL.md`：

```markdown
## 用户配置

### Vault 路径

主 Vault: ~/Documents/MyKnowledgeBase  # 修改为你的实际路径
```

### 4. 配置符号链接（可选）

在 Vault 中创建符号链接，使技能文件可访问：

```bash
# 创建到技能目录的符号链接
ln -s ~/.claude/skills "{VAULT}/99-全局技能"
```

**注意**:
- macOS/Linux: 使用 `ln -s`
- Windows: 使用 `mklink /D` (需要管理员权限)

## Obsidian 配置

### 1. 启用 Canvas 插件

1. 打开 Obsidian 设置
2. 进入"第三方插件"（Community Plugins）
3. 搜索"Canvas"
4. 安装并启用

### 2. 配置 Dataview 插件（可选）

如果使用 Base 数据库格式：

1. 在设置中搜索"Dataview"
2. 安装并启用
3. Base 文件会自动显示为表格

### 3. 配置 Vault 同步（可选）

#### 使用 Obsidian Sync

1. 在 Obsidian 设置中选择"同步"
2. 登录 Obsidian 账户
3. 选择要同步的 Vault

#### 使用第三方云服务

- iCloud (macOS/iOS)
- Dropbox
- Google Drive
- OneDrive
- Git 仓库

## 故障排除

### 问题 1: Claude Code 找不到技能

**症状**: 技能未被自动识别

**解决方案**:

```bash
# 检查技能文件是否存在
ls -la ~/.claude/skills/

# 检查文件名是否正确（注意大小写）
ls ~/.claude/skills/personal-obsidian-workflow/SKILL.md

# 检查文件权限
chmod 644 ~/.claude/skills/*/SKILL.md
```

### 问题 2: 符号链接创建失败

**症状**: `Operation not permitted` 或 `Permission denied`

**解决方案**:

```bash
# macOS: 给予终端完全磁盘访问权限
# 系统偏好设置 → 安全性与隐私 → 完全磁盘访问权限

# Linux: 使用 sudo
sudo ln -s ~/.claude/skills "{VAULT}/99-全局技能"

# Windows: 以管理员身份运行 PowerShell
# 右键 PowerShell → "以管理员身份运行"
mklink /D "C:\path\to\vault\99-全局技能" "C:\Users\YourName\.claude\skills"
```

### 问题 3: Python 脚本无法运行

**症状**: `python3: command not found`

**解决方案**:

```bash
# macOS/Linux: 确保已安装 Python
which python3

# 如果未找到，重新安装
# macOS: brew install python3
# Linux: sudo apt install python3

# Windows: 确保 Python 在 PATH 中
# 控制面板 → 系统 → 高级系统设置 → 环境变量
```

### 问题 4: 仪表盘生成失败

**症状**: 脚本报错或输出不完整

**解决方案**:

```bash
# 检查 Python 版本
python3 --version  # 应该是 3.6+

# 手动运行脚本并查看错误
python3 ~/.claude/skills/skill-dashboard-generator/scripts/generate_full_markdown.py

# 如果路径不存在，检查技能安装
ls ~/.claude/skills/skill-dashboard-generator/
```

## 验证安装

运行以下命令验证所有组件正确安装：

```bash
# 1. 检查 Python
python3 --version

# 2. 检查技能
ls ~/.claude/skills/ | wc -l  # 应该 > 2

# 3. 检查符号链接（如果已创建）
ls -la "{VAULT}/99-全局技能"

# 4. 检查 Obsidian
obsidian --version
```

如果所有命令都成功输出，说明配置完成！
